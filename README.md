# ⚖️ AI Legal Advisor

An AI-powered legal assistant for Indian citizens built with **React (Vite)** and **Express.js**. It uses the **Groq API** to provide simple, easy-to-understand legal guidance, explain laws, and answer legal queries through an intuitive chat interface.

## 🚀 Tech Stack

- React
- Vite
- Express.js
- Node.js
- Groq API
- JavaScript
- HTML
- CSS

## ✨ Features

- AI-powered legal assistance
- Simple explanations of Indian laws
- Interactive chat interface
- Fast and responsive UI

> **Disclaimer:** This project is for educational and informational purposes only and should not be considered a substitute for professional legal advice.

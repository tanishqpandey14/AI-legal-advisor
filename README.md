# AI Legal Advisor ⚖️

A free AI-powered legal assistant for Indian citizens.
Get instant guidance on Indian laws, your legal rights, and exact steps to take.

## Features
- Indian law guidance (IPC, CrPC, Consumer Act, RTI, Labour Laws)
- Dark and Light theme
- Mobile responsive
- Free to use

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- AI: Groq API (Llama 3.3)
